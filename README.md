# Library System

Настольное приложение для учёта книжного фонда и читателей библиотеки
(курсовой проект).

## Возможности

- Вход и роли: гость, читатель, администратор
- Каталог книг: добавление, редактирование, поиск
- Учёт читателей и выдачи книг
- Управление пользователями
- Диаграммы и статистика (WinForms DataVisualization)

## Стек

C# · .NET 8 · WinForms · ADO.NET · MS SQL Server LocalDB

## Запуск

1. Нужны Visual Studio 2022 и SQL Server Express LocalDB
   (ставится вместе с рабочей нагрузкой «Хранение и обработка данных»).
2. Откройте `cursuch2.sln` и запустите проект. База `Database1.mdf` копируется
   в папку сборки и подключается автоматически (`|DataDirectory|` в `App.config`).
